# J2Scrub Roadmap

## v0.1 — Foundation
- CLI
- image metadata inspection and sanitization
- local secret scanning
- dry-run Burn engine
- Linux and Windows cleanup targets
- tests and packaging

## v0.2 — Better Scrubbing
- PDF metadata
- Office document metadata
- structured redaction
- archive inspection and rebuilding
- machine-readable reports

## v0.3 — Better Burning
- cleanup profiles
- browser modules
- application plugin interface
- per-module enable/disable controls

## v0.4 — Desktop Integration
- GUI
- Windows Explorer integration
- Linux file-manager integration
- system-tray quick actions

## v1.0 — Stable
- signed binaries
- documented plugin SDK
- stable report format
- release hardening
