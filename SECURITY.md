# Security Policy

J2Scrub handles potentially sensitive local data. Security reports should avoid including real credentials, private keys, personal files, or other secrets in public issues.

For ordinary bugs, use GitHub Issues. For vulnerabilities, use GitHub's private vulnerability reporting feature when available for this repository.

Never test J2Scrub cleanup behavior against data you cannot afford to lose. Burn is designed to preview actions first, but alpha software should still be treated cautiously.
